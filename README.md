# Journali 📝

### Your thoughts, your story.

Journali is a personal journaling app that allows users to capture their thoughts, write daily entries, and keep their memories organized in one place. It provides a simple and comfortable space for self-expression.

## Main Features

- **Create Entries:** Create new journal entries with a title and content.
- **Edit Entries:** Edit existing journal entries.
- **Delete Entries:** Delete journal entries with a confirmation prompt.
- **Search:** Search for journal entries by title or content.
- **Voice Search:** Search for journal entries using voice input.
- **Bookmarks:** Bookmark favorite entries for quick access.
- **Sorting:** Sort entries by date or bookmark status.
- **Local Storage:** Save journal entries locally on the device.

## Technologies Used

- Swift
- SwiftUI
- SwiftData
  
## Project Structure
The project follows the MVVM (Model-View-ViewModel) architecture to keep the code organized and separate the user interface from application logic and data management.

- **Model:** Defines the journal entry data model.
- **View:** Contains the SwiftUI screens and UI components.
- **ViewModel:** Handles the app's logic and manages journal entries.
